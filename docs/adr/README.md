# Architecture decision records

Meaningful architecture and execution-scope deviations are recorded here using the ADR format defined in `AGENTS.md`.

## Accepted

- [ADR-001: Gemini Multimodal Vision Acceptance Set](ADR-001-gemini-vision-acceptance.md)

Do not create ADRs for routine implementation details. A change to the AI provider architecture, native OCR path, auth model, store strategy, persistence scope, navigation, or major state infrastructure requires an explicit decision.
